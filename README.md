# Bootstrap Pricing Cards

A simple and responsive pricing section built using **HTML and Bootstrap**. This project was created as part of my journey learning Bootstrap as a beginner in front-end web development.

## 📸 Screenshot



## 🚀 Features

- Three pricing plans: Free, Pro, and Enterprise.
- Clean and simple card layout.
- Pricing information and feature lists.
- Bootstrap-styled buttons.
- Consistent spacing, borders, and alignment.

## 🛠️ Technologies Used

- HTML5
- Bootstrap 5

## 🎯 What I Learned

Through this project, I practiced:

- Using Bootstrap cards to organize content.
- Creating layouts with Bootstrap's grid system.
- Styling buttons using Bootstrap classes.
- Working with spacing, borders, and alignment.
- Building a clean UI using Bootstrap without writing custom CSS.
